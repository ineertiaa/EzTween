# How to use


# 1. Import the LeanTween package
Firstly and most importantly, you must import the LeanTween unity package into your project.

Find it here: https://assetstore.unity.com/packages/tools/animation/leantween-3595

# 2. Add the script onto any Gameobject
Make sure to add the EzTween script on to any gameobject you want to act as a manager.

# 3. Make your first tween!
Make a new list item, give it a name, add the target object and play around with the settings! They should be self explanatory.

<img width="436" height="497" alt="image" src="https://github.com/user-attachments/assets/efb1009f-67f9-45a9-98ee-5b3661cbf02b" />

# 4. Trigger Tweens
To trigger a tween, drag an object with an EzTween script into a UnityEvent field.

Then, Select EzTween > DoTween and fill out the name of the Tween you want to trigger.

# 5. That's it, Easy!
